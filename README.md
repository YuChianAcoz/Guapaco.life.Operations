# Guapaco.life.Operations



## V3 點陣機下載修正
- 下載的每個車次都直接複製廠商原始 Excel 母版。
- 保留原始 Text Box / Drawing，調度姓名維持「標楷體 15pt、直排」設定。
- 保留原始頁面、印表機設定、欄寬列高與列印範圍 A1:S12。
- 右側資料庫與第二張原始資料表不輸出。
- 同一本下載 Excel 會建立「車次01、車次02…」工作表。


## V8：大正點陣機模板
- 新增「下載【大正】資料」按鈕。
- 客戶名稱改為可輸入 + datalist 建議清單，不再 readonly。
- `printer-config.js` 集中管理兩個模板的字型、字級與大正欄位位置。
- `printer-taisho.js` 獨立負責大正模板匯出。
- 大正模板由提供的 Numbers 檔轉成 XLSX 後嵌入，不需要另外上傳模板。


V9 修正：大正 Numbers 模板中的累計重量、調度員、車號、總重、空重、淨重原本是文字方塊（Drawing），不是儲存格。V8 同時保留原文字方塊又寫入儲存格，會造成重疊。本版改為直接更新文字方塊內容。
